06

渠道交付 Pipeline

可同时选择多个渠道；支持 Meta / Facebook、Google Ads、AppLovin 与 Unity Ads 交付包。

Meta 包禁止 MRAID、JavaScript 跳转和外部网络资源；HTML 与 ZIP 均需按 Meta 账号内规范检查。

响应式生成 unity-playable.html；仅竖屏或横屏分别生成对应方向 HTML；竖屏和横屏会同时生成 unity-portrait-playable.html 与 unity-landscape-playable.html。每个文件均为内联单 HTML、不得超过 5 MB，并显式声明宿主提供的 mraid.js；CTA 使用 mraid.open()。

Google ZIP 需小于 5 MB、最多 512 个文件。CTA 使用 ExitApi.exit()，最终请在 Google Ads App Campaign 预览中验证。

固定生成 applovin-playable.html。要求单文件且不超过 5 MB；资源必须内嵌，CTA 使用 mraid.open()。请在官方 Preview 中测试首个交互、横竖屏、静音和 CTA。

安装跳转配置 所有渠道共用。AppLovin 与 Unity Ads 会按设备选择并传给 mraid.open()；Meta 和 Google 仍由广告后台的 CTA 管理。

当前使用 Google Maps 测试链接；正式投放前请替换 Android 和 iOS 两个地址。
